# Why this course exists (decision context, 2026-07-06)

Condensed from the kill-first career assessment (full doc lives in the cave: `research/devops-career-pivot-2026.md`).

## The decision

DevOps is an **added second career lane alongside backend/AI — not a pivot**. Mahadi keeps applying as a backend engineer, adds DevOps-engineer applications, and uses the AI-infrastructure/MLOps framing wherever a role allows. Whichever lane produces a credible offer first wins.

## What verification found

- **DevOps demand is real** (top-5 in-demand role, postings growing) but vanilla DevOps pays *less* than AI-eng at every US level ($130–143K avg vs $140–185K), and its entry lane is flooded with rebranding applicants.
- **AI-infra / MLOps is the premium combination** — recruiters call it 2026's hardest-to-fill technical role (mid-level budgets $170–230K). Mahadi's production LLM work (multi-model routing, cost metering, eval harness) + these DevOps skills = exactly that profile.
- **Reality check:** from Bangladesh, actual income has been a struggle at ~$1,000/month despite a senior US-remote title. So US salary ceilings are irrelevant to near-term decisions — what matters is **speed to the first credible offer above threshold**, funnel width, and BD-accessible channels. A concrete modest offer beats a theoretical high one.
- **BD market insight (his own):** companies with a *dedicated* DevOps engineer are consistently better employers than those where backend devs absorb ops. Dedicated DevOps headcount = company-quality filter.
- **Income during the course:** infra work has a real freelance/contract market (server setup, CI/CD pipelines, Docker/K8s migrations) accessible with his current skills — list for small gigs from Month 1, don't wait for "finished."

## The plan this course implements

Aggressive 3–6 months, main focus, everything local at $0:

| Month | Focus | Sections |
|---|---|---|
| 1 | Docker deep · CI/CD · Linux/networking | 01–03 |
| 2 | Kubernetes + Helm | 04–05 |
| 3 | Terraform + AWS (start SAA prep) | 06–07 |
| 4 | Observability + GitOps | 08–09 |
| 5 | LLM serving infra (flagship) | 10 |
| 6 | CKA + AWS SAA + two CV variants + applications | 11 |

End state: this public repo as portfolio evidence, the capstone as flagship artifact, **two CV variants off one skill base** (backend-led and DevOps-led), CKA + AWS SAA. The skills were never the reason for being underpaid — access/distribution was. This course widens the doors; the portfolio/LinkedIn engine keeps running alongside it.
